# Demo screenshots

- `job-map-3d.png`: user-supplied application screenshot showing the 3D map of Bremen; the supplied filename is dated 22 September 2026.
- `job-map.png`: original 2D map screenshot, retained as an additional application view.
- `job-analysis.png`: two application detail captures arranged with German explanatory captions.
- `cv-review.png`: application capture of the CV checklist with German explanatory captions.
- `feature-overview.jpg`: overview of all six feature panels: interests, job map, local analysis, CV upload, completeness checklist and requirement matching.

The feature panels and original 2D map were captured from the local Mapploy application on 3 October 2026. The 3D screenshot was supplied separately for the portfolio. Job titles, counts and model outputs are historical demonstration results. Map locations are approximate; map attribution is retained. The CV demonstration uses a fictional identity and synthetic career history, not a personal CV.

Captions surround the application captures; the displayed application results were not rewritten. Quotation checks verify source text presence, not semantic correctness. Scores describe document completeness or explicit evidence matches, not hiring probability.
